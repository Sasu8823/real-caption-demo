# Deepgram ライブ文字起こしサンプル (Node.js)

アルファ版

これは、Deepgram を用いたライブ音声文字起こしの基本的な設定を示す、基本的な Express サーバーです。

コードは以下の場所にあります。

- クライアント側コード: [/public/client.js](/public/client.js)
- HTML: [/public/index.html](/index.html)
- サーバー側コード: [/server.js](/server.js)

## クライアントコード

このコードは、音声入力として使用されるユーザーのマイクにアクセスします。マイクからデータが取得されると、WebSocket 経由でサーバーに送信されます。

`data` イベントでサーバーからデータが返されると、テキストを取得して本文に追加します。

## サーバーコード

サーバーコードは、クライアントと通信するための `globalSocket` という新しい Web ソケットを作成します。クライアントからデータが受信されると、SDK 経由でそのデータを Deepgram に送信します。 (Deepgram SDK は Deepgram との Websocket 接続を確立するだけなので注意してください)。

## アプリケーションをローカルで実行する

独自の Deepgram API キーを使用して `.env` ファイルを作成します。

以下のコマンドを実行して依存関係をインストールし、アプリケーションを実行します。

```
npm i
npm run start
```

## ブラウザで実行中のアプリケーションにアクセスする

サーバーが起動したら、ブラウザで以下の URL を開きます。

```
http://localhost:3000/
```

文字起こしの準備ができたら、ボタンをクリックします。
